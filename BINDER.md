## Checkpoint Protocol - portable AI session state (open, CC0)

The open counterpart to the filed coupling method: a CC0 / public-domain protocol that lets an AI carry working state across threads and platforms via portable plain-ASCII checkpoint tokens. The human owns the artifact on their own device; the AI emits and loads it. Safe by construction: loaded state never drives outbound action without explicit human approval, and a human-edited core-state block is off-limits to the AI.

**Deployed as live operational memory (November 2026):** the protocol runs against a versioned memory vault in Mark's own Google Drive. One command loads the vault's newest index and state into any fresh thread on any platform; one token closes the session back to the vault. The thread is never the thing; the vault is.

**Published record:** protocol paper on Zenodo, DOI 10.5281/zenodo.23848058; full mechanics, lineage, and governance rules in the paper. Cross-model drift test records filed publicly in the cp-test-runs repository (synthetic test data only).
