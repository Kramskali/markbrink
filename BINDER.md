## Checkpoint Protocol - portable AI session state (open, CC0)

The open counterpart to the filed coupling method: a CC0 / public-domain protocol that lets an AI carry working state across threads and platforms via portable plain-ASCII checkpoint tokens. The human owns the artifact on their own device; the AI emits and loads it. Design intent: paste-able into any AI anywhere, safe by construction.

- **Mechanics:** token emitted at session close and pre-emptively under context pressure (marked PARTIAL if mid-task); auto-loaded at thread start; tokens pool by topic with newest-wins; conflicts recorded, not argued; loaded state never drives outbound action without explicit human approval.
- **Core-state rule:** a human-edited facts block (identity, active matters, deadlines, standing rules) the AI must never edit.
- **Lineage:** v1.0 published as a paper appendix; v2.0 hardened the mechanism (pre-emptive emit, pooling, outbound-action hard boundary); v2.1 restores the core-state ownership line. Lineage declared so forks do not confuse adopters.
- **Time-direction governance:** forward-only by design - a checkpoint is a snapshot as of its own timestamp, never a retro-update; anchor and one-way merge rules keep later facts from corrupting earlier threads.

**Now deployed as live operational memory (November 2026):** the protocol no longer lives only in pasted tokens - it runs against a versioned memory vault in Mark's own Google Drive. One command ("open my Drive") loads the vault's newest index and state into any fresh thread on any platform; one new token closes the session back to the vault. A two-lane model keeps every topic honest: a PAST lane (the newest token dated at or before the host thread's era) and a FUTURE lane (reference only, never silently merged backward). A harvest rule makes even pre-vault threads self-checkpointing on first open: the thread is dated from its own content, its facts mined into era-dated tokens, and the index updated - no copy-paste required. The thread is never the thing; the vault is.

**Published record:** Checkpoint Protocol paper on Zenodo, DOI 10.5281/zenodo.23848058. Cross-model drift test records filed publicly in the cp-test-runs repository (synthetic test data only).

*What it proves in a profile: the coupling research produced not just a filed method but a working, openly published coordination artifact - now running as persistent, platform-independent memory in daily operational use.*
